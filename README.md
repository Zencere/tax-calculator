# 个人所得税计算器（定制版）

纯静态、零依赖、离线可用的个人所得税估算工具：工资薪金 + 年终奖的年度完整计算，
年终奖「单独计税 / 合并计税」双方案实时对比，并给出 12 个月累计预扣预缴明细。

- 双击 `index.html` 即可在浏览器中使用（`file://` 协议，无需网络、无需安装任何东西）。
- 运行 `node tests.js` 可执行单元测试（断言官方权威案例，要求全部 PASS）。

## 二、使用方法

1. 用浏览器打开 `index.html`；
2. 在左侧输入各项参数，右侧**即时**重算（无需点击按钮）；
3. 输入内容自动保存到浏览器 `localStorage`，下次打开自动恢复；
4. 底部按钮：
   - **导出配置（JSON）**：把当前全部参数下载为 JSON 文件；
   - **导入配置（JSON）**：读取之前导出的 JSON 并应用；
   - **重置默认**：恢复出厂默认参数。

## 三、计算口径（定制规则）

1. **收入结构**
   - 月工资 = 基本工资 + 月度奖金（两个固定月金额，月度奖金可为 0）；
   - 年终奖 = N 个月 ×（基本工资 + 月度奖金），N 默认 2，允许小数（如 2.5）。
2. **五险一金（专项扣除）**
   - **参保城市**：预置全国 39 个主要城市的常见个人比例（养老 8% + 医疗 2% + 失业 0.5% 全国统一；公积金上海 7%、其余 12%，5%–12% 由单位自选，仅供参考），选择城市自动填入比例并联动住房租金档位建议；手动改任意比例后自动切回「自定义」；
   - **缴费基数**：默认「基本工资」，可选「全额工资（基本工资 + 月度奖金）」；
   - **缴费基数上下限封顶（可开关，默认开启）**：选择城市自动带出该市职工基本养老保险（个人）缴费基数月上限 `siCap` / 月下限 `siFloor`（2025 年度公布值）；上限 / 下限留空则该方向不封顶，也可手动修改；启用后，比例模式先按「基本工资」或「基本工资+月度奖金」取基数，再做上下限 clamp，最后乘以个人比例合计（养老 + 医疗 + 失业 + 公积金）。固定金额模式与年终奖金额计算不受封顶影响；
   - 按比例缴纳：养老 8% + 医疗 2% + 失业 0.5% + 公积金 7%（默认，全部可改），月额 = 封顶后缴费基数 × 个人比例合计；
   - 按固定金额：直接输入每月五险一金合计（与缴费基数无关）。
3. **专项附加扣除**（选择式 → 自动填标准金额，依据国发〔2023〕13 号，全国统一）：
   子女教育 2000/月·子女、3 岁以下婴幼儿照护 2000/月·孩、继续教育（学历学位）400/月、
   住房贷款利息（首套）1000/月、住房租金 1500/1100/800（按城市档位）、赡养老人 独生子女 3000/月、
   非独生子女与兄弟姐妹分摊 3000 且每人≤1500。房贷利息与住房租金互斥（二选一）；大病医疗不在此处（年度据实、汇算时填报）。
   月专项附加 = 各项自动金额之和。
4. **年终奖发放时间**（关键定制点）：下拉二选一「当年12月发」/「次年5月发（默认）」。
   主视图 = 某一个纳税年度的完整计算：该年度 12 个月每月发工资，年终奖在发放月份到账（默认 5 月）。
   选「次年5月发」时，5 月到账的年终奖是**上一年度劳动所得，按税法计入本年度汇算清缴**。
   年度口径税额与 12 月发放完全相同，仅资金到账时间与各月预扣节奏不同。
5. **计税方式**（关键定制点）：年终奖「单独计税」或「合并计税」单选；
   无论选哪种，页面始终同时显示两种方式的税额对比、更划算的一方（高亮）与差额。
6. **缴费基数上下限封顶（2025 年度，可开关）**：
   - **口径**：`siCap` / `siFloor` 为「职工基本养老保险（个人）缴费基数」月上限 / 月下限，养老 / 医疗 / 失业 / 工伤 / 公积金共用这一组口径**近似**（各地公积金缴存基数上下限与社保略有差异，本工具按社保口径近似，仅供参考）。
   - **作用顺序**：先按缴费基数选项取基数（`basic` = 基本工资，`full` = 基本工资 + 月度奖金）→ 上下限 clamp（上限 `siCap`、下限 `siFloor`，留空 = 该方向不限）→ 乘以个人比例合计。固定金额模式与年终奖金额（`N × (基本+奖金)`）不受封顶影响。
   - **数据年度**：全部为 2025 年度最新公布值（多数省份为 2025-07-01 至 2026-06-30 缴费年度；江苏、安徽、湖南、河南、山西等按自然年 2025-01-01 至 2025-12-31）。各省通常每年 7 月前后调整（灵活就业等口径另计），本工具数值仅供估算参考，实际以当地人社 / 税务部门当年核定为准。
   - **城市取值说明**：同省多数城市共用省统一标准；武汉按湖北省第 1 档（武汉和省直）；广州按广东省「广州市、省直」下限 5510（其余广东城市 4775）；深圳按广东企业职工口径 4775 / 27549；厦门按福建省全省统一标准（其灵活就业人员另有单独缴费档次，本工具不采用）。

## 四、计算公式

基本减除费用：5000 元/月 = 60000 元/年。

### 综合所得年度税率表（应纳税所得额 = 全年收入 − 60000 − 全年五险一金 − 全年专项附加）

| 全年应纳税所得额 | 税率 | 速算扣除数 |
| --- | --- | --- |
| 不超过 36,000 元 | 3% | 0 |
| 36,000 ~ 144,000 元 | 10% | 2520 |
| 144,000 ~ 300,000 元 | 20% | 16920 |
| 300,000 ~ 420,000 元 | 25% | 31920 |
| 420,000 ~ 660,000 元 | 30% | 52920 |
| 660,000 ~ 960,000 元 | 35% | 85920 |
| 超过 960,000 元 | 45% | 181920 |

应纳税额 = 应纳税所得额 × 税率 − 速算扣除数

### 全年一次性奖金单独计税月度换算表（奖金 ÷ 12 查表）

| 月均奖金（奖金 ÷ 12） | 税率 | 速算扣除数 |
| --- | --- | --- |
| 不超过 3,000 元 | 3% | 0 |
| 3,000 ~ 12,000 元 | 10% | 210 |
| 12,000 ~ 25,000 元 | 20% | 1410 |
| 25,000 ~ 35,000 元 | 25% | 2660 |
| 35,000 ~ 55,000 元 | 30% | 4410 |
| 55,000 ~ 80,000 元 | 35% | 7160 |
| 超过 80,000 元 | 45% | 15160 |

应纳税额 = 奖金 × 税率 − 速算扣除数

### 累计预扣预缴（月度明细）

- 累计收入 = 截至本月工资之和（**合并计税**模式下含当月到账年终奖，**单独计税**模式下年终奖不计入）；
- 累计减除费用 = 5000 × 月份数；
- 累计五险一金 = 月五险一金 × 月份数；
- 累计专项附加 = 月专项附加 × 月份数；
- 累计应纳税所得额 = 累计收入 − 累计减除费用 − 累计五险一金 − 累计专项附加；
- 累计应纳税额 = 累计应纳税所得额 × 年表税率 − 年表速算扣除数（≤ 0 按 0）；
- 当月预扣 = 累计应纳税额 − 上月累计已预扣（单独计税模式下，年终奖到账月另按月度换算表预扣奖金税）。

### 全年口径

- **单独计税**：工资税 =（全年工资收入 − 60000 − 全年五险一金 − 全年专项附加）× 年表税率 − 速算扣除数；
  年终奖税 = 奖金 × 月表税率 − 月表速算扣除数；全年应纳税总额 = 工资税 + 年终奖税。
- **合并计税**：应纳税所得额 =（全年工资收入 + 年终奖 − 60000 − 全年五险一金 − 全年专项附加）；
  全年应纳税总额 = 应纳税所得额 × 年表税率 − 速算扣除数。
- **汇算清缴**：全年应纳（所选方式）− 全年已预扣 = 补税（正）/ 退税（负）。
  本模型下全年预扣与全年应纳口径严格一致，故汇算清缴通常为 0；
  实际中若存在多处任职、专项附加申报调整等情形会产生补退税，本工具不模拟。

## 六、官方权威案例验证（tests.js 断言）

1. **老李**：全年工资 200,000、年终奖 24,000、全年扣除 44,000
   → 单独计税：工资税 7,080 + 奖金税 720 = **7,800**；合并计税：**9,480**；单独更划算。
2. **小张**：全年工资 120,000、年终奖 60,000、全年扣除 40,000
   → 单独计税：工资税 600 + 奖金税 5,790 = **6,390**；合并计税：**5,480**；合并更划算。
3. **五险一金只按基本工资**：基本工资 20,000、月度奖金 5,000、比例 8+2+0.5+7 = 17.5%
   → 月五险一金 = **3,500**（而非 4,375）。
4. **年终奖按基本 + 奖金**：基本 20,000、月度奖金 5,000、N = 2 → 年终奖 = **50,000**。

另含税率表边界（36,000 / 36,001 / 144,000 / 奖金 36,000 / 36,001 等）与
月度累计预扣表全年合计 = 年度税额的一致性断言。

## 七、政策依据

- 《中华人民共和国个人所得税法》（2018 年修正）及其实施条例：居民个人综合所得按纳税年度合并计算，
  基本减除费用 6 万元/年（5,000 元/月），适用 3%–45% 七级超额累进税率。
- 国家税务总局公告 2018 年第 61 号《个人所得税扣缴申报管理办法（试行）》：工资薪金所得累计预扣法。
- 国发〔2018〕41 号《个人所得税专项附加扣除暂行办法》、国发〔2023〕13 号
  《关于提高个人所得税有关专项附加扣除标准的通知》（2023 年 1 月 1 日起）：
  3 岁以下婴幼儿照护 / 子女教育 2,000 元/月·孩；赡养老人 3,000 元/月（独生子女）；
  继续教育 400 元/月（职业资格继续教育 3,600 元/年）；住房贷款利息 1,000 元/月；
  住房租金 1,500 / 1,100 / 800 元/月（按城市）。
- 全年一次性奖金单独计税：财税〔2018〕164 号；执行期限经财政部 税务总局公告 2021 年第 42 号、
  2023 年第 30 号延续至 **2027 年 12 月 31 日**。纳税人可选择并入综合所得合并计税。
- 五险一金个人缴费比例各地政策不同，本工具默认采用常见值（养老 8%、医疗 2%、失业 0.5%、公积金 7%），全部可修改。
